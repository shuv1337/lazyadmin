# lazyadmin

`lazyadmin` is a draft Linux-first Rust + Ratatui local runtime control plane.

Current status: PLAN-01 foundation workspace is scaffolded. Discovery adapters are stubs; `lazyadmin export --json` emits an empty valid snapshot and `lazyadmin diff` compares snapshot JSON.
